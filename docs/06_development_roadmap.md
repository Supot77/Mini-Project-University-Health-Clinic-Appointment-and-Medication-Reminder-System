# 06. แผนงาน 5–18 กันยายน 2569

ปรับปรุง 7 กันยายน 2569 (2026-09-07) — ฉบับ scope manual ขนาดเล็กตาม D22 ยังไม่ใช่หลักฐานว่าโค้ดหรือฐานข้อมูลทำครบแล้ว

Role contract ตลอดแผน: ผู้ป่วย (`patient`), แพทย์/เภสัชกร (`medical`) และเจ้าหน้าที่/แอดมิน (`staff_admin`)

5–7 ก.ย. ต้องได้ข้อสรุปของแบบข้อมูลและจุดเชื่อม แยกสิ่งที่รอตอบไว้ตาม [10](10_team_decisions.md) วันที่ในแผนไม่ใช่หลักฐานว่างานเสร็จ

8–11 ก.ย. พัฒนาตามเจ้าของ 12–14 ก.ย. เชื่อมนัด→ผลตรวจ→จ่ายเต็ม→รายการเตือน→บันทึก รวมสิทธิ์และ Broadcast จากนั้นวันที่ 15 หยุดเพิ่มฟีเจอร์ วันที่ 16–17 แก้บั๊กและซ้อมทั้งทีม

เกณฑ์ก่อนรวม main: lint, typecheck, build และกรณีทดสอบหลัก ก่อนนำเสนอผ่าน AC01–AC18 รวม database integration/RLS กับฐานทดสอบที่ระบุ ตรวจ Chrome ที่ 360px/1280px และใช้งานหลักด้วยคีย์บอร์ดได้

ติดปัญหาให้แจ้งเจ้าของจุดเชื่อมและคู่ตรวจ ไม่ลดขอบเขตที่ตกลงเอง รายการไฟล์ส่ง ผู้สาธิตแต่ละช่วงและผู้รวมโค้ดยังต้องเติมใน [09](09_implementation_plan.md)

## รายละเอียดแต่ละระยะ

### 5–7 ก.ย. — ล็อกฐานร่วม

- รับรองแบบข้อมูลสำหรับนัด จ่ายเต็ม รายการเตือน manual และ Broadcast
- กำหนด contract/สิทธิ์/ธุรกรรมที่ข้ามโมดูล และเตรียมบัญชีเดโม 17 บัญชี
- ตรวจ migration, RLS, RPC, repository contract และฐาน development/staging เป้าหมาย; รันหลังแบบผ่านและสำรองข้อมูลตามความเสี่ยง

### 8–11 ก.ย. — พัฒนาตามโมดูล

- ฟีม: โดเมนอีเมล, ประเภทผู้ป่วย, role/session, guarded entry pages และ RLS ของ 3 role
- ช้อป/ปาย: Supabase repositories และ role-specific containers สำหรับ slot ความจุ คิว ผลตรวจ และรายการยา
- กัญจน์/กลอง: Supabase repositories สำหรับจ่ายเต็มและรายการเตือน manual
- เฮิร์บ: Broadcast และ Dashboard แยก `patient`, `medical`, `staff_admin`

### 12–14 ก.ย. — เชื่อมและตรวจ

- ทดสอบเส้นทางจอง → ตรวจ → จ่ายเต็ม → ตั้งรายการเตือน → บันทึก รวมสิทธิ์และ validation
- ทำ AC01–AC15 ด้วย automated tests ที่ใช้ mock และทำ AC16–AC18/database integration/RLS ด้วยบัญชีทดสอบบนฐาน development/staging ที่ทีมควบคุม
- แก้ contract ที่ไม่ตรงก่อนหยุดเพิ่มฟีเจอร์

### 15–18 ก.ย. — ตรึง ซ้อม ส่ง

- วันที่ 15 ปิดรับฟีเจอร์ใหม่ ยกเว้นบั๊กที่กระทบเส้นทางหลัก/สิทธิ์
- วันที่ 16–17 รัน gates, ตรวจมือถือ/desktop/keyboard, ซ้อมตามลำดับผู้สาธิต
- วันที่ 18 นำเสนอและส่งหลักฐานที่เกณฑ์รายวิชากำหนด
