# 02. Requirements และ User Stories

ปรับปรุง 7 กันยายน 2569 (2026-09-07) — ฉบับ scope manual ขนาดเล็กตาม D22 ยังไม่ใช่หลักฐานว่าโค้ดหรือฐานข้อมูลทำครบแล้ว

## ฟีม — สมาชิกและโปรไฟล์

- ผู้ป่วยนักศึกษา/บุคลากรสมัครด้วยอีเมล @mail.wu.ac.th และรหัสผ่าน ยืนยันอีเมล เข้าสู่ระบบ ออกจากระบบ และรีเซ็ตรหัสผ่านได้
- ผู้ป่วยกรอกข้อมูลบังคับตามประเภท แก้ข้อมูลส่วนตัวและประวัติสุขภาพ มี/ไม่มี/ไม่ทราบได้ โดยไม่เปลี่ยน role เอง
- เจ้าหน้าที่ค้นหาผู้ป่วยด้วยรหัสหรือเบอร์โทร เห็นเฉพาะข้อมูลที่อนุญาต
- Admin สร้างและจัดการบัญชีคลินิก กำหนดสิทธิ์/ระงับบัญชีแล้ว session เดิมหมดสิทธิ์ทันที

## ช้อป — แผนกและตาราง

- เจ้าหน้าที่จัดการแผนก แพทย์ slot และความจุ ตรวจเวลาทับ
- เจ้าหน้าที่ดูปฏิทิน กรองวัน/แพทย์/แผนก และกรอกหรือปิด slot ด้วยตนเอง
- ข้อมูลที่มีประวัติอ้างอิงต้องไม่ลบจนความสัมพันธ์เสีย ตามฐาน Catalog

## ปาย — นัดและผลตรวจ

- ผู้ป่วยดูเวลาว่าง จอง slot และดูสถานะ/ประวัติของตน
- เจ้าหน้าที่อนุมัติ/ปฏิเสธและจัดการนัดที่ได้รับผลกระทบด้วยมือ; เจ้าหน้าที่และแพทย์จัดสถานะตรวจ โดยแพทย์ทำเฉพาะนัดตน
- แพทย์อ่านประวัติการรักษาของผู้ป่วยที่รับผิดชอบ ตรวจและบันทึกข้อมูลยา ผู้ป่วยอ่านผลหลังจบตรวจ

## กัญจน์ — คลังและการจ่าย

- เภสัชกรเพิ่ม/แก้/ระงับยา รับเข้า/ปรับยอด ดูวันหมดอายุและประวัติคลัง; แพทย์อ่านสต๊อกได้แต่ไม่แก้ยอด
- เภสัชกรดูชื่อ ประวัติแพ้ยา ใบสั่งและประวัติจ่าย โดยไม่เห็นวินิจฉัย
- เภสัชกรตรวจ stock และจ่ายเต็มตามจำนวนที่สั่งในครั้งเดียว
- หากยาไม่พอ เภสัชกรปฏิเสธการจ่ายและบันทึกเหตุผล ไม่มีแบ่งจ่าย กันยา หรือยาค้าง

## กลอง — เตือนและประวัติมื้อ

- เจ้าหน้าที่กรอกรายการเตือนจากยาที่จ่ายเต็ม ผู้ป่วยกดบันทึกผลด้วยตนเอง
- ไม่มี email, worker, missed, การเตือนซ้ำ, การพักเตือน หรือเส้นตายย้อนหลัง

## เฮิร์บ — ข้อความและ Dashboard

- เฉพาะ Admin กรอกและส่ง Broadcast ด้วยมือไปยังทุกคนหรือ role ที่เลือก
- Dashboard แสดงข้อมูลที่บันทึกแล้วตาม role ไม่คำนวณงานตามเวลาเอง

| บทบาท | Dashboard |
| --- | --- |
| Staff | นัดวันนี้ คิวคงเหลือ ภาระแต่ละแผนก |
| Doctor | คิวตนเอง จำนวนตรวจเสร็จ และนัดวันนี้ของตน |
| Pharmacist | รายการจ่ายและสต๊อกปัจจุบัน |
| Admin | บัญชี สิทธิ์ สถานะระบบ สถิติรวมที่ไม่เปิดข้อมูลผู้ป่วย |
| Patient | ไม่มีสิทธิ์เข้าหน้า Dashboard; ใช้หน้านัด ยา การเตือน และกล่องข้อความของตนโดยตรง |
