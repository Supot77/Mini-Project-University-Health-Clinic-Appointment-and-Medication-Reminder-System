# 01. ภาพรวมโครงการ

ปรับปรุง 7 กันยายน 2569 (2026-09-07) — ฉบับ scope manual ขนาดเล็ก ยังไม่ใช่หลักฐานว่าโค้ดหรือฐานข้อมูลทำครบแล้ว

ระบบคลินิกมหาวิทยาลัยและรายการเตือนแบบกรอกเอง สำหรับมินิโปรเจกต์ COE67-331 ส่งวันที่ 18 กันยายน 2569 ใช้ Next.js, React, TypeScript, Tailwind CSS และ Supabase แบบ mock; ไม่มีบริการอีเมลหรือ worker ใน scope

เส้นทางหลัก: สมัครและยืนยันอีเมล → Staff กรอก slot → Patient จอง → Staff อนุมัติ → Doctor ตรวจ/บันทึกยา → Pharmacist จ่ายเต็ม → Staff กรอกรายการเตือน → Patient บันทึกผลด้วยมือ

| เจ้าของ | งาน | ผู้ตรวจ |
| --- | --- | --- |
| ฟีม | สมาชิก โปรไฟล์ สิทธิ์และ session | เฮิร์บ |
| ช้อป | แผนก แพทย์ ตารางและ slot | ปาย |
| ปาย | นัด คิว ผลตรวจ และรายการยา | ช้อป |
| กัญจน์ | คลังและจ่ายเต็ม | กลอง |
| กลอง | รายการเตือนแบบ manual | กัญจน์ |
| เฮิร์บ | Broadcast และ Dashboard | ฟีม |

มี Dashboard ตามบทบาททั้ง 5 และ Broadcast โดย Admin การเลื่อนนัดอัตโนมัติ งานยาค้าง การแบ่งจ่าย การกันยา email และ worker อยู่นอก scope กติกาล่าสุดอยู่ใน [08](08_system_rules_and_acceptance.md) และ [10](10_team_decisions.md)

ใช้ข้อมูลสังเคราะห์กลาง 4 แผนก แพทย์ 6 คน และบัญชี 17 บัญชี ไม่รวม walk-in, Web Push, ลากวางปฏิทิน, กราฟขั้นสูง, การชำระเงินหรือเชื่อมโรงพยาบาลภายนอก รายละเอียดคืนยายังรอสรุป
