# 01. ภาพรวมโครงการ

ปรับปรุง 5 กันยายน 2569 (2026-09-05) — ข้อกำหนดสำหรับพัฒนา ยังไม่ใช่หลักฐานว่าโค้ดหรือฐานข้อมูลทำครบแล้ว

ระบบคลินิกมหาวิทยาลัยและเตือนกินยา สำหรับมินิโปรเจกต์ COE67-331 ส่งวันที่ 18 กันยายน 2569 ใช้ Next.js, React, TypeScript, Tailwind CSS และ Supabase; บริการอีเมลและ worker ต้องตรวจความพร้อมก่อนเชื่อมจริง

เส้นทางหลัก: สมัครและยืนยันอีเมล → จอง → เจ้าหน้าที่อนุมัติ → แพทย์ตรวจ/สั่งยา → เภสัชกรจ่ายหรือแบ่งจ่าย → เจ้าหน้าที่ตั้งเตือนจากยาที่รับจริง → ผู้ป่วยยืนยันเวลา → รับข้อความและบันทึกการกินยา

| เจ้าของ | งาน | ผู้ตรวจ |
| --- | --- | --- |
| ฟีม | สมาชิก โปรไฟล์ สิทธิ์และ session | เฮิร์บ |
| ช้อป | แผนก แพทย์ ตารางและความจุรอบ | ปาย |
| ปาย | นัด เลื่อนนัด คิว ผลตรวจและแก้ใบสั่ง | ช้อป |
| กัญจน์ | คลัง แบ่งจ่าย กันยาและค้างจ่าย | กลอง |
| กลอง | เจ้าหน้าที่ตั้งเตือน ผู้ป่วยยืนยันเวลา บันทึกมื้อและอีเมล | กัญจน์ |
| เฮิร์บ | แจ้งเตือน Broadcast และ Dashboard 4 บทบาท (ไม่รวม Patient) | ฟีม |

มี Dashboard ตามบทบาททั้ง 5, Broadcast โดย Admin, การเลื่อนนัดพร้อมข้อเสนอ 24 ชั่วโมง และงานยาค้างพร้อมกันยา กติกาละเอียดอยู่ใน [08](08_system_rules_and_acceptance.md) และ [10](10_team_decisions.md)

ใช้ข้อมูลสังเคราะห์กลาง 4 แผนก แพทย์ 6 คน และบัญชี 17 บัญชี ไม่รวม walk-in, Web Push, ลากวางปฏิทิน, กราฟขั้นสูง, การชำระเงินหรือเชื่อมโรงพยาบาลภายนอก รายละเอียดคืนยายังรอสรุป
