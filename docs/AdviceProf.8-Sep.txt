-(1 คะแนนทีม) วิเคราะห์ว่า user ของคุณเป็นใคร มีประเด็นอะไรที่ต้องคำนึงในการออกแบบ สีที่จะไม่ไปกระทบ user
-(4 คะแนนเดี่ยว) สิ่งที่ web ทำได้ ตรงกับ user story requirement ที่ทำไว้ไหม
